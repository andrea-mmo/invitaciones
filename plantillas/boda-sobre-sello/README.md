# Boda · sobre con sello

Invitación de boda mobile-first: sobre que se abre, cuenta atrás, cómo llegar, calendario, vestimenta, regalos, galería y formulario de confirmación por pasos.

- Idiomas: español, catalán e inglés (`shared/i18n.js`).
- Modo claro y oscuro.
- HTML, CSS y JavaScript sin framework.
- Todo lo personal (nombres, fechas, lugares, fotos, regalos) está en `shared/config.js`.
- Datos de muestra ficticios (Clara & Mateo). El formulario va en modo prueba hasta poner `endpoint` (Google Apps Script).
- Probar en local: `python3 -m http.server 8765` y abrir http://localhost:8765/d5/
